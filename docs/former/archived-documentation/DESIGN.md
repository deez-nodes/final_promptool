# REVX Design System

## 1. Brand & Concept
The REVX interface is a high-contrast, dark-mode-first environment tailored for prolonged focus during coding and prompting.

## 2. Color Palette
* **Workspace Base:** `#09090B`
* **Panel Surface:** `#18181B`
* **Text (Primary):** `#F8FAFC`
* **Text (Secondary):** `#A1A1AA`
* **Primary Accent (Fuchsia):** `#D946EF`
* **Secondary Accent (Cyan):** `#06B6D4`
* **Tertiary Accent (Yellow):** `#EAB308`
* **Success/Status (Green):** `#10B981`

## 3. Typography
* **UI Font:** `Public Sans`, sans-serif
* **Code Font:** Monospace
* **Iconography:** `Lucide` (Line icons)

## 4. Components
* **Border Radius:** `0.25rem` to `0.375rem`.
* **Buttons:** Outline style, 1px solid border matching text color.
* **Inputs:** Flat fills (`#09090B`), subtle borders.
* **Tabs:** Text-based, colored underline for active state.

## 5. Layout
* **Structure:** Persistent sidebars, resizable split-panes.
* **Dividers:** 1px borders (`#334155`).
