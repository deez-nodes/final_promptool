# Phase 1: Prove live editing

Status: Implemented and verified; awaiting user review

## Outcome

A dedicated desktop window shows the Compose reference. The user selects one prompt section and adjusts its background, font size, and padding immediately.

## Tasks

1. [01 — Launch the desktop shell](../tasks/01-desktop-shell.md)
2. [02 — Render the Compose baseline](../tasks/02-compose-baseline.md)
3. [03 — Select a prompt section](../tasks/03-section-selection.md)
4. [04 — Change three section properties](../tasks/04-section-controls.md)
5. [05 — Switch between selecting and interacting](../tasks/05-interaction-mode.md)

Run in order. Do not add presets, generalized layout editing, or full IDE functions.

## Review gate

Demonstrate: launch → select section → adjust color/type/padding → interact and edit sample text → return to selection. Show the reference and current preview at the same viewport size.

Ask the user to evaluate whether the controls help them make a disliked component look right. Finish the working slice before asking. Stop here unless further phases were explicitly authorized. Record accepted changes in the draft.

Definition of phase complete: all five task checks pass; any desktop verification limitation is explicit; the user has a concrete working slice to review.

## Delivery evidence

See [Phase 1 evidence](../PHASE-1-EVIDENCE.md). Tasks 01-05 implemented; user review pending. Phases 2 and 3 remain not started.
