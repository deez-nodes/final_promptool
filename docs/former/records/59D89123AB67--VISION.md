# promptool — vision map (llm-facing)

1. purpose
   1.1. promptool is a local single-file HTML prompt workbench
   1.2. it assembles prompts from stored parts instead of wholesale retyping
   1.3. it serves one user producing prompts for LLM work
2. core objects
   2.1. item is one saved prompt with a name, a template, and a status
   2.2. template is a named field list that structures an item
   2.3. field is one labeled slot with a hint and starter text
   2.4. component is a reusable text fragment insertable into any field
3. templates
   3.1. selecting a template prefills the editor with its fields
   3.2. each field carries starter text so common openers are never retyped
   3.3. each template maps to one technique from the Prompt Report taxonomy
   3.4. picking a technique prefills the text area with that technique's XML sections
4. autofill
   4.1. autocomplete completes the word at the cursor from words already typed in the document
   4.2. roles used in past items are reselectable from history
   4.3. context blocks used in past items are reselectable from history
   4.4. links used in past items are reselectable from history
   4.5. selecting a stored component inserts its text verbatim at the cursor
5. editing
   5.1. the editor is a plain text area with optional vim navigation
   5.2. output format toggles between markdown and xml
   5.3. a live preview compiles fields into the final prompt
   5.4. a character count tracks prompt size
6. persistence
   6.1. items save as markdown files under a chosen base directory
   6.2. item status tracks lifecycle from draft to done
   6.3. the sidebar lists all saved items for reload and reuse
7. out of scope
   7.1. no AI calls, optimize, run, chat, or bridge
   7.2. no embedded best-practice rule content
