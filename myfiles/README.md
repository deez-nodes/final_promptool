# prompTOR / PrompTool Documentation & Specs

This directory contains the complete design system specification, design tokens, TypeScript schemas, and architectural plans for **prompTOR** (also known as **PrompTool**), a professional prompt engineering IDE and AST compiler built in Nuxt 3.

## Contents

- **[DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md)**: High-contrast cyberpunk-editorial color tokens (`Acid #E8FF47`, `Cyan #39D4C8`, `Magenta #E6007A`, `Emerald #5DFFB0`), typography hierarchy, and CSS custom properties.
- **[PROMPTOOL_SPEC.md](./PROMPTOOL_SPEC.md)**: Specification-driven development plan, section block taxonomy, dynamic variable matrix, lexicon term bank, and multi-target compiler specs.
- **[tokens.json](./tokens.json)**: Machine-readable Design Token JSON definition.
- **[types.ts](./types.ts)**: TypeScript types and domain schemas for prompt documents, section blocks, variables, term bank items, and compiler AST targets.
